# Nivora Brand Assets

This folder is the canonical public brand source for Nivora by Reckley Ventures, LLC.

## Locked master logo

**File:** `nivora-master-logo.svg`

The permanent Nivora brand mark is the **mountain horizon with a rising solar/planet halo**, paired with the spaced `NIVORA` wordmark.

The permanent logo does **not** include:

- a loading/progress line
- the release name `Skye`
- a bird/eagle
- a slogan
- release-specific scenery

Those elements may appear in release artwork, boot compositions, wallpapers, and marketing, but they are not part of the master logo.

## Brand rule

**Nivora is permanent. Release themes change.**

Examples:

- Nivora Skye
- Nivora [future island name]

The master logo remains recognizable across releases. Each major release may receive its own atmospheric palette, wallpaper collection, boot composition, release art, and optional sounds while preserving Nivora navigation and identity.

## Product meaning

Nivora is a coined brand name defined by the product:

> A new horizon for everyday computing — calm, clear, adaptive, and designed to stay out of the way.

Core product statement:

> A computer that stays out of the way. Just use it. It works.

## Asset usage

Codex and Nivora build tooling should treat this folder as the upstream brand-reference source when a canonical Nivora identity asset is required.

The operating-system repository may vendor a reviewed copy for reproducible/offline builds. OS builds must not depend on a live network fetch at build or boot time.
